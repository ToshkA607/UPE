🌿 Оранжерея (Greenhouse)
Игра-симулятор от первого лица про выращивание растений, скрещивание видов и расширение оранжереи.

📖 О проекте
«Оранжерея» — это уютный симулятор, где игрок получает в наследство заброшенную оранжерею и постепенно превращает её в цветущий сад. Основной цикл: посадил семя → полил → вырастил → собрал → скрестил → продал → улучшил → расширил.

Жанр: cozy simulator, first-person
Платформа: Windows (.exe)
Статус: в разработке (учебная практика)

🎮 Игровой цикл
text
Посадил семя → Полил → Выросло → Собрал → Скрестил → Продал → Купил улучшение → Расширил оранжерею
✨ Ключевые механики
Посадка и уход — сажаешь семена в горшки, поливаешь, следишь за условиями (свет, влага, тепло).

Рост по стадиям — семя → росток → взрослое → плод.

Скрещивание — соединяешь два растения на верстаке, получаешь новое семя.

Экономика — продаёшь урожай, покупаешь удобрения, лампы, новые горшки.

Расширение — расчищаешь завалы, открываешь новые зоны (влажная, сухая, холодная).

Сюжет — находишь дневник прошлого хозяина, постепенно раскрываешь тайну оранжереи.
